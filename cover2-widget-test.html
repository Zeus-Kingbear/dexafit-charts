Cover2 cross-origin test harness

Internal testing page. This exists to load the Cover2 widget as a genuine third-party iframe on a non-cover2.ai origin — the only surface where storage partitioning, sandbox behavior, and cross-origin postMessage can be measured honestly.

No widget loaded. This page loads the Cover2 widget only from a signed test link.

To use it: in the Cover2 dashboard, open the internal test chatbot → Embed Code → Test on your live site → create a link → Or open a page of your site, with site https://charts.kingbear.co and page /cover2-widget-test.html?key=pk_… (that chatbot's public key, from its embed code).
